Python Data Cleaning and Data Quality Analysis

Project Overview

This project uses Python and Pandas to identify and clean common data quality issues in a sample customer dataset.

Objectives

- Identify missing values
- Detect duplicate records
- Standardize inconsistent city names
- Identify invalid age values
- Detect negative purchase amounts
- Generate a data quality report
- Export the cleaned dataset to CSV

Tools and Technologies

- Python
- Pandas
- NumPy
- Google Colab
- CSV

Project Files

- "Python_Data_Cleaning_Project.ipynb" — notebook containing the analysis and cleaning code
- "cleaned_customer_data.csv" — cleaned sample dataset
- "data_quality_report.csv" — data quality metrics and before/after comparison

Workflow

1. Load the sample dataset.
2. Inspect data types and missing values.
3. Identify duplicate and invalid records.
4. Clean and standardize the data.
5. Handle missing numerical values using the median.
6. Export the cleaned data and quality report.

Disclaimer

This project uses a synthetic sample dataset for demonstration and portfolio purposes.

Skills Demonstrated

Python, Pandas, NumPy, data cleaning, data validation, exploratory data analysis, and CSV reporting.
